## Glosario

| Término | Significado |
|---|---|
| **Zona** | Área del campus que la IA reconoce en una foto (ej.: Bloque A). |
| **Destino** | Lugar concreto dentro de una zona (ej.: Lab. Computación 3). |
| **Ruta** | Camino registrado por el administrador entre una zona y un destino. |
| **Waypoint** | Punto del camino (latitud, longitud e indicación). |
| **Pasillo** | Punto de cruce del campus por donde pasan las rutas (ej.: Plaza Central). |
| **Dijkstra** | Algoritmo que encuentra el camino más corto en un grafo con distancias. |
| **Semáforo** | Verde, amarillo o rojo según la confianza del reconocimiento. |
| **YOLO** | Modelo de visión artificial que detecta objetos o lugares en imágenes. |
| **Historial** | Rutas que el estudiante guardó al llegar a su destino. |
